## Your Workflow (Clean & Simple)

### Locally on Your Computer

You keep these files **only locally** (not on GitHub):
- `TRAINER_DAILY_UPDATE_TEMPLATE.md` — Your daily update guide
- `FOR_GITHUB_UPLOAD.md` — Reference for GitHub structure
- All other trainer guides and solutions
- `.gitignore` — Prevents these files from uploading

### Each Evening (for 7 days)

```bash
# 1. Open DAILY_TASKS.md
#    Replace Days 3-4 preview with full Phase 2 tasks

# 2. Commit locally (no push)
git add DAILY_TASKS.md
git commit -m "Day 1: Phase 2 tasks now live"

# 3. Push to GitHub
git push origin main
```

Interns pull next morning and see new tasks.
