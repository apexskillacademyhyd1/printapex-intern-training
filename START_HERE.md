## ❓ FREQUENTLY ASKED QUESTIONS

### "What if I don't have Python installed?"

Download from https://www.python.org/downloads/  
Check "Add Python to PATH" during install.  
Verify: `python --version` in terminal.

### "Can I use Excel instead of LibreOffice?"

Yes, Excel works fine. LibreOffice Calc is free if you don't have Excel.

### "What if I get stuck on Phase 2?"

1. Re-read the Phase 2 section in INTERN_QUICK_START.md
2. Look at the code examples
3. Google your error message
4. Ask a peer or trainer for hints (not answers)

### "Can I skip a phase?"

No. Each phase builds on the previous one.  
Phase 2 needs Phase 1 data.  
Phase 3 needs Phase 2 data.  
Complete them in order.

### "How much time should I spend per day?"

~6-7 hours per day, 7 days.  
That's approximately 49 hours total.  
Feel free to work faster, but don't exceed the 7-day deadline.

### "Can I use ChatGPT or AI to help?"

Yes for:
- Syntax questions ("How do I use regex?")
- Debugging ("Why does this error occur?")
- Explanations ("What does this code do?")

No for:
- Full solutions ("Write me Phase 2 code")
- Answers ("What's the correct business logic?")

The struggle of writing your own code is where learning happens.

### "What if I finish early?"

Great! 
- Refactor your code to be cleaner
- Add more charts and visualizations
- Write a blog post explaining your approach
- Help a peer who's struggling

Do NOT add extra work. Stay focused on the 7 days.
